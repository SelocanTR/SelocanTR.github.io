# rubeeks.co

The apex site for `rubeeks.co`, served by GitHub Pages from this repository
(a GitHub *user site*, which is what lets project repositories on this account
appear under `rubeeks.co/<repo>` — `rubeeks.co/NomadBudgetLegal` among them).

`CNAME` holds the custom domain. Do not delete it: without it the domain falls
back to `selocantr.github.io` and every project site's URL moves with it.
